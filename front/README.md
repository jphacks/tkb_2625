# ROAM — ロゲイニング参加者アプリ

参加者向けの React プロトタイプです。カード・チーム・地図の画面と、写真を承認／不承認にする管理者デモを実装しています。

## 起動・ビルド

Node.js 24 以上と pnpm 11.0.0 を使用します。`front` は独立したパッケージです。`client`・`appview` と依存関係やロックファイルを共有しません。

リポジトリ直下から次を実行してください。

```powershell
cd front
corepack.cmd pnpm install --frozen-lockfile
corepack.cmd pnpm dev
```

表示された URL（通常は http://localhost:5173 ）を開いてください。macOS/Linux では `corepack.cmd` を `corepack` に読み替えます。pnpm を導入済みなら `pnpm` も使用できます。

```powershell
corepack.cmd pnpm build
corepack.cmd pnpm preview
```

成果物は `front/dist/` に生成します。静的ホスティングでは、`/cards` などのパスを `index.html` にフォールバックする設定が必要です。既存の本番デプロイは `client`・`appview` が対象です。

## 画面と確認手順

1. `/cards`：9件のチェックポイントを表示します。4種類の提出状態での絞り込み、配点・名前・状態順の並び替えを確認できます。
2. 未提出の「緑の歩道橋」を開き、画像なしの提出エラーを確認してから、画像を選択・提出します。JPEG・PNG・WebP、8MBまで対応します。
3. `/admin`：提出写真を承認すると、初期の80ptに40ptが加算されます。ヘッダー・カード・チーム画面で120ptになることを確認します。不承認時は理由の入力が必要です。
4. 「不可」の「森の喫茶室」から再提出します。`/team` で以前の提出履歴も確認できます。
5. `/map`：架空の経路・チェックポイントを表示します。実測GPSは「記録開始」で取得を開始し、停止または画面の離脱で監視を解除します。
6. `/admin` の「大会を終了する」で提出を停止できます。「デモを初期化」で写真・審査結果・終了時刻を初期状態に戻します。

## デモの制約

- 大会・チーム・メンバー・場所・配点はサンプルです。目標画像と初期の提出画像はSVGイラストです。
- 提出画像・履歴・終了時刻は localStorage に保存します。画像は長辺1200px以下のJPEGに縮小します。保存に失敗した操作は反映せず、エラーを表示します。
- 終了時刻は初回起動／デモ初期化から3時間です。保存済みの終了時刻は再読み込みで延長しません。
- API接続、認証、複数端末・複数タブの同期はありません。`/admin` は保護されていないデモ画面です。同じタブ内で確認してください。
- UIのデータ取得・更新は `src/service.js` と `src/useRogaining.js` に分離しています。本番接続ではAPIの応答への変換と認証・権限制御が必要です。

## 地図と端末機能

[Leaflet](https://leafletjs.com/) と [OpenStreetMap標準タイル](https://operations.osmfoundation.org/policies/tiles/)を利用しています。APIキーは不要です。地図内に出典を表示しています。背景地図の取得にはネットワーク接続が必要です。

GPSにはHTTPSまたはlocalhostと、ユーザーの位置情報許可が必要です。スマートフォンからPCのLANアドレスにHTTP接続する場合はGPSを利用できないことがあります。実測経路は画面内のメモリにのみ保持し、離脱・再読み込みで消去します。バックグラウンドやスリープ中の記録継続は保証しません。

地図は北が上です。「端末の方位を確認」でセンサー値が取得できた場合に端末の向きを表示します。カメラ・GPS・方位センサーは対応端末で確認してください。
